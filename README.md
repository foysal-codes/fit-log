# FitLog

FitLog is a dark, responsive workout library for choosing lifts, building a five-exercise daily plan, and saving workouts for later.

## Technologies

- Next.js App Router and React
- TypeScript
- Tailwind CSS
- FitLog workout API
- Browser localStorage for plan persistence

## Key features

1. Browse and sort a responsive workout library.
2. Open detailed workout pages with specs and instructions.
3. Add up to five exercises to Today's Plan.
4. Save workouts, mark planned lifts as done, and remove entries.
5. Persist plan and saved workouts across reloads with live navbar counters.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
